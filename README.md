# 발주공고 맞춤발송 에이전트 (bid-alert-agent)

나라장터·NIPA·NIA 공고를 키워드/공고 종류/사업예산 조건에 맞게 필터링해 매일 아침 메일로 발송하는 에이전트입니다.

## 구조

```
나라장터 API → (OpenClaw 크론) → 구글 드라이브 발주목록 시트
                                        │
웹 신청폼 (index.html) ──POST──▶ Apps Script (Code.gs)
                                        │
                              신청자별 조건 필터링 → 메일 발송
                              (신청 즉시 1회 + 매일 오전 8시)
```

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 공고 맞춤 발송 신청 웹폼. GitHub Pages로 호스팅 |
| `Code.gs` | Google Apps Script. 신청 접수(`doPost`), 확인 메일, 매일 발송(`dailySend`), 공고 필터링·발송(`sendMail`) |
| `logo.svg` / `logo.png` | LABQ 로고 (SVG는 index.html에 base64로 내장됨) |

## 주요 동작

- **신청 접수**: 웹폼 제출 → `doPost`가 응답 시트에 행 추가, 확인 메일 + 오늘 공고 즉시 발송
- **중복 신청 처리**: 같은 이메일의 기존 '활성' 신청을 자동 '비활성' 처리 → 항상 최신 신청 기준으로만 발송
- **필터링**: 키워드(사업명), 공고 종류(나라장터 본공고/사전공고/발주계획, NIPA, NIA), 사업예산 규모(5억/20억/40억 미만/모두)
  - 배정예산이 없거나 파싱 불가한 공고는 예산 필터를 통과시켜 항상 포함
- **수신 기간**: 1~3개월, 만료 시 자동 '비활성' 처리
- **마감임박 표시**: 마감일 3일 이내 공고는 메일에서 하이라이트

## 배포

### Apps Script
1. 응답 스프레드시트 → 확장 프로그램 → Apps Script에서 `Code.gs` 내용 반영
2. 배포 → 새 배포 → 웹 앱 (실행: 나 / 액세스: 모든 사용자)
3. 발급된 `/exec` URL을 `index.html`의 `SCRIPT_URL`에 설정

> 코드 수정 후에는 배포 관리에서 **새 버전으로 재배포**해야 반영됩니다 (URL은 유지됨).

### 웹폼 (GitHub Pages)
저장소 Settings → Pages → Branch를 `main`으로 설정하면 `index.html`이 호스팅됩니다.
